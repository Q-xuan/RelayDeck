# UI 体验优化计划

目标：把整体使用体验打磨到 90 分。已完成的部分见下方「已完成」，剩余项按收益排序，逐条可独立实施。

## 已完成

- 全局设计令牌化（颜色 / 边线 / 阴影全部走 CSS 变量），深色模式一键切换并持久化
- 字号整体提升一档（正文 12–13px，说明 11px），提高可读性
- 2 秒轮询改为快照签名比对：内容不变时只原地刷新计时文本，不再整页重绘，悬停与光标不丢失
- 输入中 / 弹窗打开 / 窗口隐藏时暂停轮询；搜索框跨渲染保持焦点与光标位置
- 原生 `window.confirm` 全部替换为应用内确认弹窗（主题化、中文按钮、Esc 取消 / Enter 确认、危险操作红色主按钮）
- 弹窗清理挂在 DOM 移除上：任何路径关闭弹窗都会解绑快捷键并把焦点还给触发按钮
- 视图切换入场动画（仅在切换视图时播放，轮询重绘不闪）；切换视图回到顶部，同视图重绘保持滚动位置
- `/` 快捷键聚焦当前页搜索框；`prefers-reduced-motion` 下关闭全部动画
- 自定义滚动条、按钮 hover 阴影、扫描中按钮转圈、统计数字千分位
- Provider 列表：状态筛选 chips、排序、健康趋势 sparkline、冷却倒计时徽章、模型锁定标记
- 会话页：六格统计、筛选 / 排序 / 搜索、归档与恢复、修复可见性横幅

## 剩余项

### P1 交互补全

- [ ] Provider 拖拽排序：行内拖拽替代弹窗里的上移 / 下移按钮（HTML5 drag 或 pointer 事件，落点后调 `move_provider`）
- [ ] 列表变更动画：Provider / 会话行的新增、移除、重排加 FLIP 过渡，避免行位置瞬移
- [ ] 快捷键面板：`?` 呼出快捷键一览（`/` 搜索、`1-5` 切视图、Esc 关弹窗）；`1-5` 切视图本体
- [ ] Toast 可操作化：失败 toast 附「重试」按钮；归档 / 删除 toast 附「撤销」（归档可逆，删除前置归档所以也可撤）

### P2 信息呈现

- [ ] 活动页按时间分组（今天 / 昨天 / 更早），支持按 Provider、状态码筛选
- [ ] 延迟趋势图：控制台加最近 24h 平均延迟迷你折线（数据已在 healthHistory，聚合即可）
- [ ] 会话列表虚拟滚动：180+ 行时只渲染视口内的行（现在全量渲染，行数上千会卡）
- [ ] 请求详情弹窗：点活动行展开完整错误信息、尝试链路（哪些节点失败后切到哪个）

### P3 无障碍与细节

- [ ] toast 容器加 `aria-live="polite"`，错误用 `assertive`
- [ ] 弹窗焦点圈闭（Tab 不逃出弹窗）
- [ ] 表格列头可点击排序（替代右上角下拉）
- [ ] 空状态插图统一风格（现在是图标 + 文案，可加简单线条插画）
- [ ] 窗口宽度 < 1040px 时的降级布局（当前设了 min-width，缩窗会出横向滚动）

## 验收标准

- 所有交互不依赖原生浏览器 UI（confirm / alert 已清零，保持）
- 任何 2 秒轮询周期内无可感知闪烁、无焦点丢失（保持）
- 键盘可完成全部高频操作：切视图、搜索、确认 / 取消
- 深浅两套主题下所有组件对比度达 WCAG AA
